Make your own portfolio like Flair’s

portifol Studio helps you build a simple, pretty personal page and publish it with GitHub Pages. No coding needed — just answer a few questions, add pictures and links, and we’ll turn it into a website.

What you can do:
  • Pick a colour, profile picture, and banner
  • Add a bio, stats, badges, and social links
  • Show your local time, interests, and extra sections
  • Save everything to a GitHub repository and publish it

Examples of pages made with this tool look like clean profile cards with photos, buttons, and interest cards — similar to Flair’s community pages.

Connect with a GitHub token

To save your portfolio, this page needs a short-lived personal access token (PAT) from GitHub.

Warning about shared devices: Tokens and public or shared computers don’t mix well. Anyone who uses this browser after you could use your token to change files. Prefer your own private device, and delete the token in GitHub when you’re done.
1
What is a PAT?

A personal access token is like a temporary password that lets this page talk to GitHub on your behalf. It expires, so it’s safer than your real password.

2
How to make one

Go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

Step-by-step
  1. Open Fine-grained tokens.
  2. Click “Generate new token”.
  3. Give it a name, set expiration to 1 day (or longer if you prefer).
  4. Under Repository access, choose “Only select repositories” or “All repositories” depending on what you want.
  5. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else off.
  6. Generate and copy the token (starts with github_pat_).
3
Scopes / permissions this program needs

Contents: Read and write. That’s it. Metadata is usually granted automatically. Do not give more permissions than needed.

We’ll store it in this browser’s local storage so you don’t have to paste it every time.

Turn on GitHub Pages

Your repository is ready (a small starter file was added if it was empty), but the website isn’t published yet. Let’s turn on GitHub Pages so people can see your portfolio. This is super easy!

1
Open the Pages settings

Click the big button below. It will open a new tab with the exact page you need.

Open Pages settings ↗
2
Choose how to publish

On that page, look for “Build and deployment” or “Source”.

  • Select Deploy from a branch.
  • For the branch, pick the one that says main or master (usually the first one).
  • For the folder, pick / (root).
  • Then press the green Save button.

That’s it! GitHub will start building your site. It can take a minute or two.

Before we connect

A personal access token is a temporary key. It lets this page save your portfolio to the one repository you choose. This page forgets the key when refreshed.

Keep it safe: Fine-grained token · expires in 1 day · one repository · Contents read/write only.
What am I agreeing to?

GitHub’s API does not let this page verify token expiry or permissions. Do not use a shared computer, never share the token, and delete it in GitHub if you gave it more access than listed. By continuing, you agree to follow GitHub’s Terms of Service and Community Code of Conduct.
